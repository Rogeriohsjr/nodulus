# OpenCode developer: write the scenario test
Write real tests first for the requested behavior. Run them and observe a relevant assertion failure before implementation. A missing import or syntax error is not RED. If needed create a minimal importable stub that exhibits the missing behavior. Leave production behavior unimplemented for the next node.
Return dev-work.v1 with summary, changedFiles and validation including exact RED command and failure. For documentation-only requests explicitly record the non-TDD exception and verification plan instead.
